# ADVERB MASTER AI

Interactive Progressive Web App for Chapter XXI – Adverbs
A Text-Book of Higher English Grammar (Rules 263–278 + Exercise 30)

## Features
- Complete original textbook content for Rules 263–278
- Clear Bengali explanations for every rule
- Interactive Classification explorer
- Comparison tables (regular, -ly, irregular)
- Position of Adverbs trainer with word-order practice
- Full Exercise 30 (20 original questions)
- 100-question mixed assessment
- Progress tracking (localStorage)
- Offline-capable PWA
- Mobile-first responsive design
- Text-to-speech for English examples
- Search across all rules

## Deploy to GitHub Pages
1. Create a new repository (e.g. adverb-master-ai)
2. Upload all files from this folder
3. Settings → Pages → Deploy from main branch, root folder
4. Site will be at https://YOUR_USERNAME.github.io/adverb-master-ai/

## Local Test
Open index.html in a browser or run: npx serve .

Made for West Bengal Board students (Classes IX–XII)
